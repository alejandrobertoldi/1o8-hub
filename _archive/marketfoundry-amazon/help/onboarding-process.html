Onboarding Steps

1
Create Client
Create the client record in the app. This is the first entry point — all subsequent steps depend on the client existing in 1o8 Hub.
Client ID Code
Formed as {FIRST 3 LETTERS OF CLIENT NAME}_{MARKETPLACE}_{COUNTRY}.
Example: Toad Elemental on Seller Central US → TOA_SC_US
Status
Active Set when creating a new client that is onboarding. Default for any new client starting work with 1o8.
Prospect A potential client who needs limited access to test the app before officially onboarding. They can log in but have restricted visibility.
Inactive A former client no longer working with 1o8. Do not use when creating a new client. See the Client Status Changes section for Drive folder consequences.
Template
AIA Already In Amazon — the client already has products listed on Amazon. Use AIA.
NTA New To Amazon — the client has no existing listings on Amazon. Use NTA.
Save Changes
Once all fields are filled in, click the Save Changes button to create the client record.
2
Assign Team
Assign team roles for this client. Once all required team members have been added, this step is automatically marked as complete.
3
Setup Asana Project
Create a project in Asana under 1o8 with onboarding, content, and PPC sections. Asana is the source of truth for task-level tracking. Once the team is assigned, remaining onboarding tasks are auto-assigned to the Account Manager (1o8), except FeedbackWhiz which goes to the Executive Strategist. Creating the project generates the Asana Project ID, which is stored on the client record and used to link all subsequent task assignments.
Link an existing Asana project
If the client is already in our system but the Asana project was not imported into the hub, you can link it manually instead of creating a new one. In Asana, open the project, click the dropdown next to the project name → Copy project link, then paste it into the "Link an existing Asana project" text field in the hub. The Project ID is extracted automatically from the pasted link.
4
Setup Starting Day & Timeline
Set the onboarding start date and initialize the 13-week Gantt timeline from the AIA or NTA template. This anchors all deliverable due dates.
5
Add Client Users
Set up all client-side access to the 1o8 Hub portal. Consists of 4 sub-tasks completed in sequence, then saved to the hub.
Add Contact Email(s)
Enter the client's contact email address(es) for portal access and communication.
Add Client Account(s)
Add client's Gmail account(s) to 1o8 Hub Users section (Admin → Users).
Assign Client Role
Set user role to "client" in Admin → Users.
Assign Client Project
Link the user to their client account (assign clientIdCode) so they see only their data.
Add to Hub
Once all users are filled in, click the Add to Hub button to register them in 1o8 Hub.

8
Amazon Access
Obtain and configure access to the client's Amazon account. Includes importing catalog data to register products in the hub.
Request Amazon Access
Request access to Amazon Seller Central from the client.
Provide Team Access
Provide all relevant team members access to Amazon Seller Central.
Import Product Attributes (CLR)
Upload the Amazon Category Listing Report (.xlsm) to register attribute schemas and, for AIA clients, stage per-SKU values. Prerequisite for generating a listings sheet.
📍 Location in Seller Central: ☰ (three-line menu) → Reports → Inventory Reports → Category Listing Reports
Link SKU↔ASIN (ALR) and merge to master AIA only
Upload the Amazon All Listings Report to stage SKU↔ASIN links, then merge staged CLR + ALR data into master (filtered by status).
📍 Location in Seller Central: ☰ (three-line menu) → Reports → Inventory Reports → All Listings Reports
Generate Listings Sheet AIA only Optional
Create a Google Sheet with minimum + necessary attributes for the client to fill in. Imported back as new master listings.
9
Setup Intentwise
Configure Intentwise analytics integration for Seller Central and Sponsored Ads data. 5 sequential sub-tasks.
Get Merchant ID
Retrieve the Merchant ID from Amazon Seller Central.
📍 Location in Seller Central: Seller Account → Account Info → Merchant Token
Request Subscriptions
Contact Intentwise with the Merchant ID to request Amazon Seller Central and Amazon Sponsored Ads subscriptions.
Enter Intentwise ID & Name
Enter the Intentwise ID and Intentwise Name provided by Intentwise after subscriptions are set up.
Request Enable
Request Intentwise to enable both Amazon Seller Central and Sponsored Ads subscriptions.
Confirm Enabled
Confirm that both Amazon Seller Central and Sponsored Ads subscriptions are active and enabled in Intentwise.
10
Setup Intentwise AMC
Configure Amazon Marketing Cloud (AMC) subscription through Intentwise for advanced advertising analytics. 4 sequential sub-tasks.
Request Amazon Marketing Cloud
Contact Intentwise to request Amazon Marketing Cloud (AMC) subscription setup.
Enter AMC ID & Name
Enter the Intentwise AMC ID and Intentwise AMC Name provided by Intentwise after AMC is set up.
Request Enable
Request Intentwise to enable the Amazon Marketing Cloud subscription.
Confirm Enabled
Confirm that the Amazon Marketing Cloud subscription is active and enabled in Intentwise.

Setup FeedbackWhiz

Client Status Changes & Drive Consequences

Marking a Client as Inactive
  • ⚠️A confirmation dialog is displayed in the app before any change is saved.
  • 📁The client's root Drive folder is automatically moved from the 1o8 Hub shared drive to the Inactive Clients folder.
  • 🔒The client's status is set to Inactive in the database and synced to BigQuery.
  • 👁️The client still exists in the system and all data is preserved — nothing is deleted.
Re-activating an Inactive Client
  • ⚠️A confirmation dialog is displayed in the app before any change is saved.
  • 📁The client's root Drive folder is automatically moved from Inactive Clients back to the root of the 1o8 Hub shared drive.
  • ✅The client's status is set to Active in the database and synced to BigQuery.
  • 🔄All existing data, products, and folder contents are fully restored — no re-onboarding required.
Prospect Clients & Drive Routing
  • 📁When you run Create Drive Folders for a Prospect, the full {CLIENT_ID_CODE}_{Client Name} tree is created inside the Prospect folder instead of at the root of the 1o8 Hub shared drive.
  • 🔁Changing an existing client's status re-homes its root Drive folder to match: Prospect → Prospect folder, Active → 1o8 Hub shared-drive root, Inactive → Inactive Clients.
  • 🗑️If a folder was previously sent to Trash, re-running Create Drive Folders now recreates the tree instead of reusing the trashed folder.
Active → User selects Inactive → Confirmation dialog → Inactive + 📁 → Inactive Clients
Inactive → User selects Active → Confirmation dialog → Active + 📁 → 1o8 Hub Drive
⚠️ Both operations require explicit confirmation. If the user cancels the dialog, the status is not saved and the Drive folder is not moved. The Drive move is best-effort and runs asynchronously — if Drive is unavailable the status change still saves, and the error is logged server-side.
