Overview

How 1o8 generates last month's Amazon report, reviews it internally, and emails the client. Everything happens on Clients → Monthly Report (/reports/monthly). Filter Waiting for me to see only your queue.

4th
Autogenerate cron — 08:00, 10:00 and 12:00 UTC on the 4th. Each client is its own job so a timeout cannot stop the rest.
PM → AM → CEO
Review order. Status is a 2×5 table: Generated, PM, AM, CEO, Sent
CEO
CEO Approve sends the letter automatically. Only Jake can approve at that step.

Where the team works

Hub page: /reports/monthly. Done steps are struck through and ticked. Do not trust last month's numbers on days 1–3 — Amazon / Intentwise settlement lags 3–4 days. In View, PM / AM / CEO add a client note at the end of each section to explain the numbers.

3. Client notes (PM / AM / CEO)

Personalized context for the client, written at the end of each report section. These are not the same as Send back notes, which stay internal.

How to add a note

On /reports/monthly, open View. Scroll to the end of a section. Use Note for the client, then Add note or Save note. Clearing the box and saving removes that section’s note.

Only the assigned PM, assigned AM, Jake, or an admin override can write. Notes are allowed at any review stage, including after send.

Where the client sees them

Hub View (editable for reviewers). Portal full report (read-only). Client letter after the KPI, advertising, and highlights blocks (other section notes stay on the full report).

Regenerating a report keeps existing notes. The Drive PDF / HTML archive only picks up new notes on the next generate. Cover and table of contents cannot take a note.

4. What the client receives

Client letter

From 1o8 <reports@marketfoundry.agency>.
Reply-To is the AM, not the shared reports inbox. A plain Reply goes to the AM.
Cc is the AM and the CEO so both stay on Reply-All.

Subject: Client — Month Year performance. 600px HTML: greeting, lede, headline KPIs, MoM tables, 3–5 highlights, plus any client notes saved on those blocks, then Click for more details opens the full report in the client portal (/portal/reports/monthly?period=YYYY-MM).

No PDF, no SVG, no Drive link. Under Gmail's 102 KB clip limit. Send is blocked if the client has no AM email — it will not fall back to reports@.

Hub archive (internal only)

A4 landscape PDF and HTML sibling in Drive. View / Open PDF / Download HTML on /reports/monthly. Same JSON the letter is built from.

After send, Client send shows datetime, Resend last event (delivered / bounced / failed / sent), and to-addresses. Resend id is stored on the row.

Recipients

AAC ClientContactEmail1–5 plus portal client/prospect users on that account. AmazonContactEmail is never used. Hub toggles plus optional custom addresses (max 10) are sent as the enabled list. Toggles live in the browser (localStorage), not Postgres.

5. Staff emails (internal)

Internal review pings go through Resend before anyone sends the client letter. From is 1o8 Hub <reports@marketfoundry.agency>. Reply-To is the same inbox. Client letters keep Reply-To as the AM.

Resend must have marketfoundry.agency verified (sending enabled). If it is not, PM/AM/CEO pings return 403 and the report still saves. The subdomain reports.marketfoundry.agency is not used.

6. Hub checklist for each reviewer

Step Do this Do not
PM Open Waiting for me. View the report. Add a client note at the end of any section that needs context. If numbers are wrong, Regenerat that client only, then Approve. Regenerate All. Do not Send (button is hidden). Do not put internal review comments in client notes.
AM Check the report and notes. Preview Email. Approve, or Send back with an internal note. Only your own clients. Approve someone else’s client. Do not skip the PM. Do not Send to the client.
CEO Open Waiting for me. Spot-check notes. Approve & send — the letter goes out automatically. Approve before AM is done. Admin/owner cannot click this unless they are Jake.
