Overview

How to create, scope, build, and version Amazon A+ Content inside Design → A+ Content. Each set targets one ASIN, a complete variation, or a selected group of ASINs. Every version has its own Google Drive folder and manual status.

Choose the Right Scope

Scope controls which Amazon listings receive the content. Select it carefully before building modules because each set keeps its own versions, assets, and Drive folders.

ASIN

Assigns the set to one product. Search by ASIN, SKU, or title, then select the product row.

Variation

Assigns the set to a parent and every ASIN in that variation family. Search for and select the parent ASIN.

Group

Assigns one set to a selected subset of ASINs. Group members may come from one variation or multiple variations under the same client.

✓ Use Group when content is shared by a theme value. Examples include one color, size, flavor, or style across several variation families.

Create an A+ Set

1
Open the client
Go to Design → A+ Content, choose the client, then click New A+ Set.
2
Choose the scope
Select ASIN, Variation, or Group. The product controls below the scope change to match your choice.
3
Choose Premium or Basic A+
Premium A+ supports up to 7 premium modules. Basic A+ supports up to 5 standard modules. The module picker only shows modules available for the selected tier.
4
Choose the marketplace
Confirm the marketplace before creating the set. The marketplace is part of the set identity and its editor URL.
5
Create the set Automatic
Click Create set. 1o8 Hub creates V01, creates the version and Master Files folders in Google Drive, then opens the module editor.

Create a Group Set

Group scope supports quick filtering by variation theme and precise checkbox selection. At least two ASINs are required.

1
Select Group
Choose Group in the scope selector. All variations is selected by default and does not require a parent anchor.
2
Choose where to browse
Keep All variations to search the client's full variation catalog. Choose One variation when you want to select a parent and limit the member list to that family.
3
Filter by theme attributes
Use the available Color, Size, Flavor, and Style filters. You can select more than one value and combine filters.
4
Select the ASINs
Tick individual checkboxes or use Select visible to select every currently filtered result. Selections stay selected when you change filters or move between variation families.
5
Review links and create
Click an ASIN to open its product detail page. Use the Amazon icon for the live Amazon page. Only the checkbox changes group membership. Confirm at least two selected ASINs, then create the set.

Group naming

An active theme filter becomes part of the set and Drive folder name. A Nordic Dreams color group is named like {CLIENT}_G01_Nordic_Dreams_APlus_V01. Group numbers increase per client. If no filter is active, the fallback label is Selected_ASINs.

Build and Review Content

Add modules

Use the bulk module picker to add several categories at once, or click Add module for one module. Reorder modules and remove any that are not needed.

Complete text and assets

Fill the module fields and upload the required desktop or mobile assets. The editor enforces Amazon dimensions, character limits, and repeatable-item limits defined for each module.

Generate alt text

Use the Edit suggestion pill next to the orange Generate Alt Text pill (Sparkles) in the version header, or Alt text on a module. Empty suggestion fills only missing alts; a filled suggestion regenerates and is sent with the current alt. Details in AI Alt Text below.

Preview the result

Use the desktop and mobile previews on the client set page. Carousel modules include arrows and position indicators so each slide can be checked.

AI Alt Text

An optional Edit suggestion pill sits next to an orange generate pill with a Sparkles icon. The suggestion is guidance for the model, not the alt itself.

Version header

Edit suggestion sits next to Generate Alt Text and generates alts for that version. Leave the suggestion empty to skip images that already have alt text. Fill it to regenerate; the suggestion is sent with the current alt.

Module header

Image modules use the same Edit suggestion + orange Alt text generate control. That run covers the module's main image. Carousel and other repeatable-item images keep the same pair under the image slot.

Alt fields

Each alt is a three-line textarea (100 characters). Amazon A+ alt is per-image: desktop and mobile share one value. An orange copy icon on the alt label copies the current value. Edit suggestion does not have a copy icon.

Review before approval

Generated text lands in the field immediately. Read it, edit by hand if needed, then continue the status workflow.

Versions, Drive, and Status

Version folders

Each version has a separate Drive folder plus a Master Files subfolder. Open it from Link to Drive folder. Add large source files directly to the Master Files folder.
