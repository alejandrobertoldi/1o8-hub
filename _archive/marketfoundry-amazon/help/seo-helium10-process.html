SEO Manager — complete process (S0–S8)

SEO Manager turns product facts, keyword research, customer reviews, and Alexa for Shopping answers into reviewed Amazon listing content, then takes it through team and client approval before it is pushed to the Hub catalog. Everything happens on one project page: phases are stacked cards, and each card unlocks when the one before it is approved.

For the full step-by-step SOP with roles, rules and checklists, open SEO Manager SOP (full).

The project page

  • One page, nine phases. S0 Setup through S8 Push are cards on the same page. The left menu lists every phase and its sub-steps; click any unlocked item to jump to it.
  • One click per approval. Approving a phase unlocks the next one straight away: the approved card collapses and the next card opens. There is no separate "Continue" step.
  • Status. Each phase shows Approved, In progress or Locked. S6 sub-sections show LOCKED (done and protected) or UNLOCKED (editable).
  • AI model. The AI · Opus 4.7 pill at the top right shows the Claude model the AI steps use; hover it to see the model per step.
  • Local saving. Work is saved to the project as you go. Approvals are what move a project forward — generating content alone is never an approval.

S0 — Project Setup

  1. Open SEO → Content Control Center and select New Project.
  2. Select Client, then Target ASINs (marketplace and parent/child variation scope).
  3. Content Rules: choose which sections are shared across variations and which need variation-specific content. Sections are Title, Bullet Points (one set of 5), Description and Backend.
  4. Name & Assignee, then Confirm & Create.

S1 — Intake: establish the source facts

  1. Project Summary: verify client, brand, marketplace, ASINs and variation details.
  2. Variety Pack Details (when shown): confirm contents and quantities.
  3. Baseline Analysis: pick the baseline version per ASIN and correct missing or wrong facts.
  4. Competitors and Brand Guidelines: add competitors; upload or paste guidelines (voice, audience, words to avoid, supported claims). The full guidelines are sent to every AI step.
  5. Confirm & Approve S1.

S2 — Keywords: Cerebro CSV upload

Helium 10 is used through CSV exports. The direct Helium 10 connection is switched off; keywords come from a Cerebro CSV you export from Helium 10.

  1. Step 1 — Copy ASINs into Helium 10 Cerebro: use Copy variation ASINs (child ASINs; the parent is excluded), run Cerebro, export the CSV.
  2. Step 2 — Upload the Cerebro CSV for the product. Optionally upload competitor Cerebro CSVs.
  3. Review Parsed Data, apply filters, then run tiering and review the keywords (tiers, intent, negatives).
  4. Approve S2.

S3 — Reviews: review CSV upload

  1. Upload the review CSV for the parent ASIN (required columns: id, text, date, title, rating). Reviews already stored in the Hub can be used instead with Use Hub reviews.
  2. Check the parsed reviews, run the AI analysis, and review themes, praise and objections.
  3. Approve S3. If the product has no reviews, use Skip — No Reviews Available.

S4 — Alexa for Shopping

  1. Phase 1: copy the question block into Amazon's Alexa for Shopping chat, paste the five answers back, confirm the mapping.
  2. Phase 2: generate (or use default) strategic questions, collect the answers the same way, confirm.
  3. Run the analysis, review the Q&A insights, approve S4.

Answers from Alexa are research to verify, not proof that a claim is correct.

S5 — COSMO

  1. Check the prerequisites (S1–S4), then Generate COSMO Map.
  2. Remove unsupported or irrelevant relationships, then approve S5.

S6 — SEO Content (S6.1–S6.8)

  1. S6.1 Configuration — confirm settings (e.g. size placement) and lock.
  2. S6.2 Titles — Title (≤75 chars) and Item Highlight (≤125 chars).
  3. S6.3 Bullet Points — one set of 5 bullets, 180–200 characters each (never over 200).
  4. S6.4 Description and S6.5 Backend Search Terms (byte limit applies).
  5. S6.6 Audit & Optimize — run the audit, fix findings in the batches.
  6. S6.7 Premium A+ Q&A — Module 7 questions and answers; uses all bullets, the full description and the full brand guidelines.
  7. S6.8 Final SEO Content — review everything per ASIN, then Save & Submit for review. This locks S6 and starts S7.

Keyword tables (S6.2–S6.5). Every table shows where each keyword is already used, in the same order: Title · Item Highlight · Bullets · Description · Backend. The first checkbox shows whether the keyword is in this step's text — untick to remove, tick to add — then Regenerate. Columns update by themselves when another step is generated.

Editing. Click a text cell to edit it. The lock icon in a cell's left margin protects it from regeneration.

S7 — Review & Share with Client

  1. The review tracker shows each sign-off: SEO Manager (submitted) → Project Manager → Account Manager → Client (when sent).
  2. Reviewers comment directly on the preview, or edit text on the spot during PM/AM review; every edit is logged with a before/after.
  3. Project Manager approves or requests changes (a note is required).
  4. Account Manager either Sends to client or Approves as final (a reason is required).
  5. The client reviews in the portal and can suggest edits; the team accepts or declines each suggestion. The client then approves.

Overrides. Someone higher on the client team (Account Manager or Executive Strategist) can act on a lower step through a separate Override checkbox. Approving your own submission is only allowed for the client's Account Manager or Executive Strategist.

S8 — Push Content to Products

  1. Once a revision is approved, S8 pushes that approved revision to the Hub product records.
  2. Preview the changes, check matched and unmatched ASINs, then confirm.

Pushing updates Hub products and queues them for BigQuery publishing; it does not publish to Amazon by itself.

Content rules that apply everywhere

  • Prohibited terms — one list drives both the AI and the S6 compliance check: medical claims (e.g. "medicine", "cure", "FDA approved"), guarantees, superlatives ("best", "#1") and promotional wording ("sale", "% off", "free shipping"). Flagged terms show as critical; edit the text or regenerate with feedback.
  • Bullets — one set of 5; Concise, Content and Key Features versions are retired.
  • Changes after submission — S6 stays locked after Save & Submit; use Unlock for Editing to change it. Submitting text identical to the approved revision is refused.

Troubleshooting

  • A phase is locked — approve the phase before it; generating content is not approval.
  • Keyword or review upload fails — check the CSV columns and that the file is for the right product.
  • A critical prohibited term — edit the cell or regenerate with feedback; bypass only when the word is genuinely allowed.
  • New data not showing (e.g. thumbnails after an update) — do a full page reload.
  • Push shows unmatched ASINs — fix the catalog records and preview again before confirming.
