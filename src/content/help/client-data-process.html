Overview

Each client's Main KPIs (Clients → Client Summary, Client Reports) are computed from its data sources, pulled into the hub every morning at about 4–5 AM Central. A source is connected once it's set on the client's profile (Contract & services → Main KPIs). New sources bring ~13 months of history on their first sync, so last year's comparisons work right away.

5
Sources — GA4 · Meta Ads · Google Ads · Klaviyo · Shopify
Daily
Automatic sync every morning; admins can run it now in Sync & Export → KPIs
Read-only
The hub only reads numbers; it never changes anything in the client's accounts

1. Connecting Each Source

1
Google Analytics (GA4)
The client adds analytics@1o8.agency as a Viewer on its GA4 property. Then pick the property on the profile. Sessions, conversion rate and site revenue come from here.
2
Meta Ads
The client's ad account must be shared with 1o8's Business Manager. Then pick it on the profile (several can be picked; they're added up).
3
Google Ads
The account must be under 1o8's Google Ads manager account (MCC 359-589-4352). Type its customer ID (123-456-7890) on the profile. Without it, Google Ads spend still shows if the account is linked to the client's GA4 property.
4
Klaviyo
In the client's Klaviyo: Settings → Account → API keys → create a Read-only private key. Paste it on the profile (Add key); nobody can see it again. Email revenue, flows vs campaigns, engagement and list growth come from here.
5
Shopify
Type the store's brand.myshopify.com domain on the profile. Each store has its own 1o8 Hub app (Shopify Dev Dashboard, custom distribution to that store): Add app keys (client ID + secret), then Connect and approve in Shopify. Net sales, orders and new customers come from here.

2. Checking That It Works

Admin → Sync & Export → KPIs

Shows each source's connection and the history of syncs: every client and source with the days pulled, and any error in red. Sync now pulls everything immediately. Then open the client's report (Client Reports → Sales, Paid Media, Email, Traffic) and compare one month against the platform.
