# /due-diligence

Thin preset over the Claudify Analyst engine: investor-grade diligence on a company
or deal. `/due-diligence "<target>"` = `/research --preset=diligence` with the
strategist directed to:
- frame the decision as write-the-check vs pass, with the loss ladder elicited in
  those terms (a wrong check vs a missed winner),
- build the tree around: the numbers as claimed vs verifiable, the moat, the team
  and execution risk, the red-flag scan (every claimed metric that cannot be traced
  to a primary source is itself a finding),
- run the bear with independent collection by default (diligence is the one preset
  where the thin-pool trigger is presumed),
- render with the investor dossier template.
Every claimed metric gets the scope-bound entailment treatment: right number, wrong
entity is the most common diligence trap. Private output only. No em dashes.
