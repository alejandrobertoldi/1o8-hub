# SEO Pipeline Premium Upgrade

## What This Is

A comprehensive upgrade to 1o8Hub's Amazon SEO content pipeline (S1-S6) that integrates gstack SEO skill intelligence at every phase, adds competitor research, brand voice extraction, and grouped variation generation. The goal is to produce premium, conversion-optimized Amazon listings that read like the brand wrote them — at scale for 20+ clients/month — while being fully optimized for Amazon's AI systems (Rufus and COSMO).

## Core Value

Every Amazon listing generated by this pipeline must sound like the brand's own copywriter wrote it, while being invisibly optimized for Amazon's search and AI discovery systems.

## Context

**Existing system:** 1o8Hub has a production S1-S6 SEO pipeline serving Amazon marketplace clients. The pipeline generates listing content (titles, bullets, descriptions, backend keywords) using Claude API. Content passes through intake → keywords → reviews → Rufus Q&A → COSMO mapping → generation + audit.

**Current pain points:**
1. Generated content feels generic — keywords stuffed without natural flow
2. No competitive differentiation — content could be any brand's listing
3. Missing brand voice — doesn't capture client's tone or personality
4. Weak bullet structure — hierarchy not optimized for scanning or conversion
5. Rufus/COSMO validation is manual and inconsistent

**Variation system:** Products are organized into variation families with groups (flavors, sizes, styles). The variation builder supports multi-group membership via a junction table. Currently, SEO projects can be linked to variations but content generation doesn't leverage the family context for differentiation.

**Scale:** 20+ clients/month, each with multiple ASINs. Pipeline must produce premium quality without manual per-listing intervention.

**Brand data sources:**
- Client websites (scrapeable via headless browser)
- Brand guideline PDFs stored in Google Drive (per-client folders, to be organized)

## Constraints

- **Data preservation**: All existing SEO project data must be preserved — migrations only, no data loss
- **Incremental deploy**: Ship in phases — pipeline stays operational throughout the upgrade
- **Current stack**: Next.js 16, Supabase PostgreSQL, Claude API, Google Drive — no new infrastructure
- **Existing integrations**: Must work with current BigQuery import, SP-API, and export workflows
