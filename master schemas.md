## AAC: Hub-only fields (PG-only, no BQ equivalent)

These columns live on `public.aac` but are **intentionally not synced to the
BigQuery `1o8Hub.AAC` table**. They are hub-internal workflow metadata that
predates or replaces BQ tracking, and adding BQ counterparts is out of scope.

| PG column                  | Type                       | Purpose                                             |
| -------------------------- | -------------------------- | --------------------------------------------------- |
| `client_type`              | enum (`AIA`, `NTA`)        | Onboarding template — drives Gantt + Asana flows    |
| `onboarding_date`          | timestamp with time zone   | Hub-side onboarding kickoff date                    |
| `portal_timeline_enabled`  | boolean (default `false`)  | Toggles client portal's onboarding timeline tile    |
| `asana_project_gid`        | varchar(100)               | Asana project GID created during onboarding         |

Editing flow: write directly to PG via the `aac` PATCH endpoint
(`/api/clients/[clientIdCode]` PATCH); skip the `updateAacFieldInBigQuery`
call. They do not appear in `AAC_COLUMNS` (the BQ column whitelist) because
they have no BQ source.
