# SEO S5: COSMO — SOP

> Standard Operating Procedure for generating COSMO framework outputs used to structure positioning and final listing copy.

---

## 1. Overview

S5 (“COSMO”) is used to assemble structured messaging inputs for S6, typically including:

- Core positioning and customer framing
- Feature-to-benefit mapping
- Competitive context (when available)

---

## 2. Who can do this

- **viewer**: view COSMO outputs
- **editor/admin**: generate/re-generate and approve S5 (depending on UI controls)

---

## 3. Where to find it (Navigation)

- **URL**: `/seo/{projectId}/cosmo`

---

## 4. Inputs

- Best results when S1 + S2 are solid, and S3/S4 are done when available

---

## 5. Outputs

- COSMO maps / framework outputs saved to the project
- Approved S5 (when approved in the UI)

---

## 6. Step-by-step procedure

1. Open `/seo/{projectId}/cosmo`.
2. Generate COSMO outputs.
3. Review for:
   - Clear positioning and differentiation
   - Consistency with brand guidelines
   - No disallowed claims
4. Iterate (adjust S1 context if needed) and regenerate.
5. Approve S5 in the UI.

---

## 7. Common issues / troubleshooting

- **COSMO feels off-brand**
  - **Cause**: guidelines are vague or missing
  - **Fix**: strengthen S1 brand guidance and regenerate
