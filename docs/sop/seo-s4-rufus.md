# SEO S4: Rufus Q&A — SOP

> Standard Operating Procedure for generating Rufus-style Q&A content and using it to improve listing copy.

---

## 1. Overview

S4 generates a set of questions and answers designed to:

- Address customer objections proactively
- Clarify product usage and differentiators
- Provide structured messaging inputs for downstream copy

---

## 2. Who can do this

- **viewer**: view Rufus Q&A outputs
- **editor/admin**: generate/re-generate and approve S4 (depending on UI controls)

---

## 3. Where to find it (Navigation)

- **URL**: `/seo/{projectId}/rufus`

---

## 4. Inputs

- Completed S1 intake
- Best results when S2 keywords (and S3 reviews if available) are approved

---

## 5. Outputs

- Rufus Q&A content stored to the project
- Approved S4 (when approved in the UI)

---

## 6. Step-by-step procedure

1. Open `/seo/{projectId}/rufus`.
2. Generate Rufus Q&A.
3. Review each Q&A for:
   - Claim safety (especially if regulated categories)
   - Alignment to brand guidelines from S1
   - Coverage of key objections and use-cases
4. If needed, refine S1 guidelines and regenerate.
5. Approve S4 in the UI.

---

## 7. Common issues / troubleshooting

- **Answers include non-compliant claims**
  - **Cause**: intake compliance guidance is missing
  - **Fix**: add compliance docs/guidelines in S1, then regenerate
