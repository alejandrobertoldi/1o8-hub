# 1o8Hub App SOP (User Playbook)

This folder contains **Standard Operating Procedures** for each major section of the 1o8Hub app (currently located at `1o8-Bible/web`).

Use this as the starting point for onboarding, training, and “how do I…?” reference.

---

## How to use this SOP

- **If you’re new**: start with `roles-permissions.md`, then `ui-shell.md`, then `dashboard.md`.
- **If you’re doing catalog work**: read `products-list.md` and `product-detail.md`, then `publish.md` and `export.md`.
- **If you’re doing SEO work**: start with `seo-overview.md`, then follow S1–S6 pages in order.

## SOP authoring conventions

- Each SOP should include: **Overview**, **Who can do this**, **Where to find it**, **Inputs**, **Outputs**, **Step-by-step**, **Common issues**, and **FAQ**.
- Prefer **copy-pastable labels** the user sees in the UI (button text, page names).
- If a workflow differs by role, document differences explicitly.
