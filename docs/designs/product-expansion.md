## Vision

### 10x Check
The 10x version transforms 1o8Hub from an internal ops tool for 1o8 Agency into the operating system for Amazon sellers. Brand managers sign up, connect Seller Central, and within 30 minutes have auto-imported products, AI-generated A+ content, SEO audits, live sales dashboards, and one-click publishing back to Amazon. Not a tool for your agency — the platform for Amazon commerce.

### Platonic Ideal
Opening 1o8Hub feels like having a senior Amazon optimization consultant 24/7. Conversational instead of form-based — tell the AI about your product and it fills out 972 fields with citations from Amazon style guides and competitor analysis. Proactive — the system notices ACOS climbing before you do and drafts recommendations. One-click publishing. Client self-service with guardrails. Revenue attribution that proves ROI.

## Accepted Scope (added to this plan)
- Revenue Attribution: content change → before/after sales snapshot → impact card on product page + portal
- Client Portal Upgrade: approve/reject A+ content, inline comments, file upload, activity feed
- Observability Dashboard: Claude usage/cost tracking, external service health, error log, data freshness
- Cmd+K Command Palette: global search across products, clients, ASINs, SEO projects

## Deferred to TODOS.md
- AI Copilot Layer: conversational AI sidebar embedded across all workflows (L effort, build after attribution proves ROI)
- Amazon SP-API Write-Back: direct publish to Amazon from Hub (L effort, high risk from Amazon approval)

## Additional Decisions Made During Review
- Redshift error handling: add try/catch wrapper to queryRedshift() with graceful fallback (10 min fix)
- Revenue attribution trigger: piggyback on existing sales dashboard loads (zero new infra)
- Test framework: bootstrap Vitest with 5-10 critical path tests
- Redshift pool: bump max connections from 5 to 10
- Data architecture: keep Redshift (Intentwise-managed) + BigQuery (internal) split as-is

## Architecture Notes
- All expansions fit cleanly into existing architecture
- No new external dependencies required
- Revenue Attribution needs new `content_impact_snapshots` table
- Observability needs new `api_usage_log` table
- Portal upgrade extends existing role system and section access controls
- Cmd+K is pure frontend + one API endpoint
