# CEO Plan: SEO Manager → Content Control Center

## Vision

### 10x Check
The SEO Manager becomes a Content Control Center — think GitHub for Amazon SEO. Every piece of content has a version timeline. You can diff any two versions. Quality scores are tracked over time. Export history shows exactly what went to the client and when. Bulk operations let you approve/export entire client batches at once.

### Platonic Ideal
A manager opens the SEO Manager Monday morning. The view shows their clients in a grid. Red badges on clients where quality is dropping. Green badges where everything is current. They click into "Trejo's Tacos" and see all 11 projects with a content preview — the title, bullet points, description right there, no clicking into each project. They spot that version 3 of the Mug project has a compliance word flagged. They click "Compare Versions" and see a side-by-side diff — v2 vs v3. They approve it, select 5 projects, hit "Export All" and a Google Doc is generated. The export is logged with timestamp and content snapshot.

## Key Decisions
- Manager keeps current route `/seo/manager` — no new routes needed
- Content previews from Supabase `seo_asins.generatedContent` (not BQ) — enriched in projects API response
- Version diff computed client-side (`diff` npm library, `diffWords()`)
- Quality scores stored in new Supabase table, not BQ (need fast reads for badges)
- Bulk operations use single polymorphic endpoint with `action` field
- Export tracking insert-after-upload (no phantom records on failure)
- Bulk export uses `Promise.allSettled` with `p-limit(5)` concurrency
- Projects API uses 4-query bulk + JS join (avoids N+1)
- New features extracted to `src/components/seo/manager/` (keeps page.tsx as orchestrator)
- `useOutsideClick` hook extracted in this PR (DRY — 5 usages)

## Design Spec (from /plan-design-review)

### Card Layout — 4-Tier Hierarchy

```
┌─────────────────────────────────────────────────────────────────┐
│ [☐]  Project Name                    [Assignee] [S4 Rufus] [⋮] │  TIER 1: Identity
│      Brand · Created Mar 1                                      │
│                                                                 │
│ ●●●●○○  S1 S2 S3 S4 S5 S6     [Quality: 82] [Exported ✓]     │  TIER 2: Status
│                                                                 │
│ Title: "Trejo's Tacos Ceramic Mug — 16oz Dishwasher Safe..."   │  TIER 3: Content
│ B1: "Premium ceramic construction with hand-painted Trejo's..." │  (always visible)
│ Desc: "Enjoy your morning coffee in style with this..."         │
│                                                                 │
│ ▸ Versions (3)    ▸ Export History (2)                          │  TIER 4: Drill-down
└─────────────────────────────────────────────────────────────────┘
```

- Content preview always visible (CEO vision: "no clicking into each project")
- Versions + Export History are accordion sections (collapsed by default)
- Bulk checkbox appears only in "Select" mode (toggle button in header)
- Quality sparkline: 40x16px inline SVG next to quality badge, tooltip on hover

### Quality Badge Thresholds
- Score 80+: `bg-emerald-50 text-emerald-700 dark:bg-emerald-500/10` (green)
- Score 60-80: `bg-amber-100 text-amber-800 dark:bg-amber-500/20` (yellow)
- Score <60: `bg-red-50 text-red-600 dark:bg-red-500/10` (red)
- No score: no badge shown (graceful absence, not "N/A")

### Export Badge
- Never exported: `bg-stone-100 text-stone-500` → "Never exported" (muted)
- Exported: `bg-emerald-50 text-emerald-700` → "Exported ✓" with relative date

### Version Timeline
- Stacked version cards (not horizontal dot timeline) — functional over decorative
- Each card: `v3 — 3 fields changed — Mar 15` with `Compare ↔` button between adjacent pairs
- Nested cards use `rounded-lg` (smaller than parent `rounded-xl`)

### Diff Modal
- Inline diff (not side-by-side) — Amazon content is long text
- Red strikethrough for removals (`bg-red-100/50 line-through`)
- Green underline for additions (`bg-emerald-100/50 underline`)
- Shows only changed fields — unchanged collapsed with "N fields unchanged" summary
- Full-screen sheet on mobile, centered modal on desktop
- `role="dialog" aria-labelledby="diff-title"`

### Bulk Mode
- Activated by "Select" button in header (next to "+ New Project")
- Card selection: amber-50 bg tint + visible checkbox (44px touch target)
- Bulk bar: fixed bottom, `shadow-lg` upward, same card border tokens
- Actions: Approve | Export All | Reassign — disabled until 1+ selected
- Export progress: "Exporting 3/5..." with per-project status on partial failure
- Keyboard: Tab through cards, Space toggle, Shift+Click range, Escape deselect all

### Interaction State Matrix

| Feature          | Loading              | Empty                                  | Error                        | Success                | Partial            |
|------------------|----------------------|----------------------------------------|------------------------------|------------------------|--------------------|
| Content Preview  | Shimmer (3 rows)     | "No content yet — complete S6" + link  | "Failed to load" retry       | Title+B1+Desc          | Title only         |
| Version Timeline | "Loading versions..."| "No versions in BQ yet"                | "Failed to load" retry       | Stacked cards          | 1 version, no diff |
| Quality Badge    | — (loaded w/ card)   | No badge                               | —                            | Colored badge          | —                  |
| Export History   | "Loading..."         | "Never exported" (muted)               | "Failed to load"             | "Last exported Mar 15" | —                  |
| Bulk Action Bar  | —                    | Hidden (0 selected)                    | —                            | "3 selected" + actions | —                  |
| Bulk Export      | "Exporting 3/5..."   | —                                      | "2 of 5 failed" retry/skip   | "5 of 5 exported"      | Per-project status |
| Diff Modal       | "Computing diff..."  | —                                      | "Diff failed"                | Inline red/green       | —                  |

### Responsive
- Mobile (<768px): title-only content preview (tap to expand), full-screen diff sheet
- Bulk checkboxes: 44px touch targets, `safe-area-inset-bottom` on action bar
- Quality badge: number only on mobile (no "Quality:" label)

### Accessibility
- Quality badge: `aria-label="Quality score: 82 out of 100, good"`
- Export badge: `aria-label="Last exported March 15, 2 total exports"`
- Bulk bar: `role="toolbar" aria-label="Bulk actions for N selected projects"`
- Diff modal: `role="dialog" aria-labelledby="diff-title"`
- Keyboard: Tab → Space toggle → Shift+Click range → Escape deselect
