## Vision

### 10x Check
SEO Mission Control — a manager opens /seo Monday morning and in 10 seconds knows: which clients need attention, who on the team is doing what, what shipped last week, what's next. Every pixel earns its space. Zero clicks to answer "how's our SEO work going?"

### Platonic Ideal
A control tower that feels information-dense but not overwhelming. Stale projects surface automatically. Team workload is visible. The phase funnel reveals bottlenecks. Recently completed work gets celebrated. Clicking any dimension (client, team member, phase) filters the entire view instantly.

## Accepted Scope (added to this plan)
- Hero metrics row (total projects, completed this month, avg completion rate, total ASINs, exports delivered)
- Client health cards with aggregate progress bars, color-coded status, mini phase breakdown
- Client card click → /seo/clients/[clientId] detail page
- Per-client detail page: full project list, phase breakdown, export history, "Open in Manager" link
- Team workload strip with avatars, project counts, relative load bars, click-to-filter
- Phase funnel visualization showing pipeline distribution across S1-S6 + completed
- Stale project alerts (7+ days without phase approval, using max(s1-s6_approved_at))
- Recent activity feed (last 10-15 actions from phase approvals + exports)
- Recently completed section (projects done in last 30 days with time-to-completion)
- Quick-filter by assignee from team strip (toggle on/off)
- Sidebar nav update: SEO Dashboard + SEO Manager + SEO Config

## Key Decisions
- Stale detection: based on max(s1_approved_at ... s6_approved_at), NOT updatedAt
- Client cards only show clients with 1+ SEO projects
- Dashboard shows only clients with SEO projects (empty clients filtered out)

## Implementation Approach
Approach A→C hybrid: Dashboard + Route Restructure + Per-Client Detail
- New /seo/page.tsx = SEO Dashboard
- Move current /seo/page.tsx to /seo/manager/page.tsx = SEO Manager
- New /seo/clients/[clientId]/page.tsx = Per-Client Detail
- New API endpoints:
