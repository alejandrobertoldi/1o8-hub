<h1>Seller Central Case Studies — Template Instructions</h1>

<h2>1 · What this template is</h2>
<p>Two sibling formats sharing one visual language (slate teal, charcoal cards, orange accent, Outfit):</p><ul><li><strong>Detailed / Granular</strong> — 14 slides. The deep dive: monthly sales chart, product mix, demand curve, paid media by channel, and four creative slides.</li><li><strong>High-Level</strong> — 5 slides. The executive summary: Cover (headline + 3 KPI chips + client card), The Challenge (start vs target), The Results (six proof points), The Approach (five pillars), The Creative (brand story + 9-tile listing grid + A+ + storefront, orange CTA band).</li></ul><p>Fill rules, voice, charts and image-slot behaviour below apply to both; chart-drawing (§5) applies to the detailed deck only. Pick High-Level for prospects and quick shares; Detailed for QBRs and case-study deep dives.</p><p><strong>Figure banding (High-Level only).</strong> Private absolute $ figures — revenue, ordered sales, ad-attributed sales, spend, ASP, starting-point sales — never show real numbers: band them as "Low/Mid/High N-Fig" (e.g. Mid 7-Fig). Percentages, ratios (ROAS, growth multiples), impression/unit counts and module/ASIN counts stay real. Where a $ context line would leak a figure, swap it for a ratio (e.g. "on $28.5K spend" → "1.3× blended ROAS"). The Detailed deck is internal/QBR-facing and keeps exact figures. It is a single self-contained HTML file (plus <code>assets/image-slot.js</code> for drag-and-drop image slots). Every client value is written as a bracketed placeholder like <code>[CLIENT NAME]</code> or <code>$[0.0]M</code> — fill every bracket, drop in creative assets, and the deck is done.</p>
<p>Navigation: arrow keys, click, or swipe. Slides are <code>&lt;section class="slide" data-label="…"&gt;</code> children of the deck stage; the file scales itself to any window.</p>

<h2>6 · Image slots — the rules that matter</h2>
<p>Slots are <code>&lt;image-slot&gt;</code> elements. Three ways to fill one: <strong>drag a file</strong> onto it, click <strong>Browse file</strong>, or click <strong>Paste Drive link</strong> (Drive logo pill) and paste a Google Drive share link or any direct image URL — paste auto-submits. Share Drive files to the <strong>marketfoundry.agency domain</strong> ("anyone in this domain with the link") — public sharing is not needed; images load for anyone signed into their work Google account. A filled slot shows <strong>Replace / Edit / Delete</strong> controls on hover (Edit = pan/zoom reframe; Delete clears the drop and reveals any baked <code>src</code>). Key attributes: <code>fit="cover|contain|width"</code>, <code>align="top"</code>, <code>shape</code>/<code>radius</code>, <code>placeholder</code>, and <code>src</code> for a committed file.</p>
<div class="callout warn"><strong>The workflow: draft with Drive links → bake → export.</strong> Reports are drafted internally (all image handling by marketfoundry.agency users, domain-shared Drive links — short URLs that never hit the persistence cap). Before sharing anything externally, <strong>bake every image to a committed asset</strong> (e.g. <code>assets/&lt;slug&gt;-li-3.webp</code>, wired via the slot's <code>src</code>): Drive links only render for signed-in domain users, so an unbaked deck looks broken to clients. Dropped <em>files</em> (not links) live in a hidden state file with a size cap — bake those too and clear the state file. Then export the shareable PDF/PPTX from the baked deck.</div>
<ul>
<li><strong>Storefront slots</strong> use <code>fit="width" align="top"</code> — full-page screenshots show from the top and crop at the bottom.</li>
<li><strong>A+ stacks</strong> use <code>fit="cover"</code> in fixed 1200/492 frames so modules butt flush.</li>
<li><strong>Cover hero / logo / brand story</strong> use <code>fit="contain"</code> — never crop brand art.</li>
<li>Recommended native sizes: A+ modules 1200–1464px wide; brand story banner ~1464×625; listing images square ≥1000px; storefront full-page captures ~3000px wide.</li>
</ul>

<script>
(function(){
  var stage = document.querySelector('deck-stage');
  var W = +stage.getAttribute('width')||1920, H = +stage.getAttribute('height')||1080;
  var slides = Array.prototype.slice.call(stage.querySelectorAll('section.slide'));
  var idx = 0, n = slides.length;
  stage.style.width = W+'px'; stage.style.height = H+'px';
  slides.forEach(function(s,i){ s.style.display = i===0 ? 'block':'none'; });
  document.getElementById('tot').textContent = n;

  function fit(){
    var sc = Math.min(window.innerWidth/W, (window.innerHeight)/H);
    stage.style.transform = 'translate(-50%,-50%) scale('+sc+')';
  }
  function show(k){
    idx = Math.max(0, Math.min(n-1, k));
    slides.forEach(function(s,i){ s.style.display = i===idx ? 'block':'none'; });
    document.getElementById('cur').textContent = idx+1;
    document.getElementById('prog').style.width = ((idx+1)/n*100)+'%';
  }
  document.getElementById('prev').addEventListener('click', function(){ show(idx-1); });
  document.getElementById('next').addEventListener('click', function(){ show(idx+1); });
  document.addEventListener('keydown', function(e){
    if(['ArrowRight','ArrowDown','PageDown',' '].indexOf(e.key)>-1){ show(idx+1); e.preventDefault(); }
    else if(['ArrowLeft','ArrowUp','PageUp'].indexOf(e.key)>-1){ show(idx-1); e.preventDefault(); }
    else if(e.key==='Home'){ show(0); } else if(e.key==='End'){ show(n-1); }
  });
  // click halves (ignore clicks on nav)
  document.addEventListener('click', function(e){
    if(e.target.closest('#nav') || e.target.closest('image-slot')) return;
    var x = e.clientX / window.innerWidth;
    if(x > 0.62) show(idx+1); else if(x < 0.38) show(idx-1);
  });
  // wheel nav, debounced
  var wlock=false;
  window.addEventListener('wheel', function(e){
    if(wlock) return;
    if(Math.abs(e.deltaY) < 24 && Math.abs(e.deltaX) < 24) return;
    wlock=true; setTimeout(function(){wlock=false;}, 520);
    if((e.deltaY||e.deltaX) > 0) show(idx+1); else show(idx-1);
  }, {passive:true});
  // swipe
  var tx=0,ty=0;
  window.addEventListener('touchstart', function(e){ tx=e.touches[0].clientX; ty=e.touches[0].clientY; }, {passive:true});
  window.addEventListener('touchend', function(e){
    var dx=e.changedTouches[0].clientX-tx, dy=e.changedTouches[0].clientY-ty;
    if(Math.abs(dx)>50 && Math.abs(dx)>Math.abs(dy)){ show(dx<0 ? idx+1 : idx-1); }
  }, {passive:true});

  window.addEventListener('resize', fit);
  fit(); show(0);
  setTimeout(function(){ var h=document.getElementById('hint'); if(h) h.style.transition='opacity 1s'; if(h) h.style.opacity='0'; }, 4000);
})();
</script>
